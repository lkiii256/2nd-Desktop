Menu to start the 2nd desktop in tty3

How to Open 2nd Desktop With This:

  • Step 1: Press Ctrl + Alt + F3 and log in
  • Step 2: Go to the directory of the file but if you downloaded it and didn't move the file, type "cd Downloads" and then type "./anothersesh.sh" and type 1, Press Ctrl + Alt + F2 to go back to the other desktop

How to Close 2nd Desktop With This:

  • Step 1: Right click anothersesh.sh
  • Step 2: Press 2 and press Ctrl + Alt + F2
